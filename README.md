# SPACE RIDERS: Skippy's Quest

A top-down 16-bit action-adventure starring Skippy. Free, in the browser: https://sanyziahj.github.io/skippys-quest/

- Chapter 1: The Desert Star Shard (Santt, ROS, the Sand Dungeon, the Void-Eye Centipede)
- Chapter 2: The Seaport (Cash's Portal Nexus, the Pirate King, Ramshackle the Viking, the Sea Cave, the Void Kraken)

Controls: Arrows/WASD move, X attack, Z item, Q/Tab swap item, C roll, E/Space talk, Enter map/pause, M mute. Touch controls on mobile. Progress autosaves.
